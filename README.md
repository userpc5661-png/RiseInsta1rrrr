# مَشهد

تطبيق Flutter للآيفون بواجهة عربية للبحث في كتالوج iCinema وتصفّحه. يعرض النتائج من الخدمة وقت الطلب، بما فيها تفاصيل الأعمال والمواسم والحلقات وعدد الترجمات المعلن لكل عنصر.

## بناء IPA على GitHub

افتح Build Mashhad iOS في تبويب Actions. يبدأ البناء تلقائيًا عند دفع تغييرات المشروع إلى main، ويمكن تشغيله يدويًا. الناتج Mashhad-iOS-unsigned.ipa من قسم Artifacts، مع بصمة SHA-256. يحتاج الملف توقيعًا قبل التثبيت على الآيفون.

## تشغيل معاينة ويندوز

من مجلد المشروع، ابْنِ المعاينة وشغّلها بالأوامر التالية. تستخدم المعاينة اتصال جهازك بخدمة iCinema.

~~~text
flutter pub get
flutter build web --dart-define=CATALOG_ORIGIN=
python tools/preview.py
~~~

## تشغيل نسخة الآيفون

على macOS مع Xcode وFlutter 3.47.2 أو أحدث:

~~~text
flutter pub get
flutter run
~~~

للتصدير افتح ios/Runner.xcworkspace، واختر فريق التوقيع ومعرّف التطبيق الخاص بك، ثم نفّذ flutter build ipa. الحزمة تتضمن مشروع Xcode، وبناء نسخة موقّعة يحتاج إعدادات حساب Apple.

## طريقة الربط

- الرئيسية والبحث وتصنيفات الكتالوج والتفاصيل تستخدم واجهات القراءة العامة لخدمة iCinema. الكتالوج يُحمّل على صفحات حسب الطلب.
- العناوين التي تحفظها وآخر العناوين التي تفتحها تُحفَظ على جهازك.
- زر المشاهدة يفتح صفحة العمل، ومع المسلسلات يفتح الموسم المختار. تختار الحلقة والترجمة وتتحكم في التشغيل من مشغّل iCinema.
- الحساب والغرف والتعليقات وطلبات المحتوى والبث المباشر تفتح صفحات iCinema داخل متصفح التطبيق على iOS. في المعاينة تفتح في تبويب المتصفح.
- التطبيق يعتمد على توفر الخدمة وممتلكات المحتوى التي تعرضها. ملفات الفيديو والترجمات وحسابات الخدمة تبقى لدى iCinema.
